# Image provenance

`probe-points.webp` is a cropped, resized/compressed and annotated derivative of the owner's original `1000075612.jpg`. The six A–F markers use the exact contact coordinates preserved in `data/probe-checks.json`. No components are reconstructed. The image depicts the original, pre-modification state.

`boardview-samsung.svg` is a deterministic rendering of selected pad coordinates from the privately held BoardView. It reflects native X to match the microscope photo. Component outlines are schematic; it contains no copper-trace reconstruction and is not a screenshot from a commercial viewer.

Only verified-source derivatives are active references. Withdrawn AI-generated guides are not included. Original commercial design files and private supplier media remain excluded. No additional public licence has been selected for these project assets.
